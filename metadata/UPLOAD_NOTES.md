Status: UPLOADED.

The package contains authored notebooks/Python scripts, CSV inputs/results, GIS layers, compressed large shapefile bundles, and a publisher-final paper reference retained locally. It does not contain personal or controlled-access human-subject data. The GitHub upload uses Git LFS for the 131 MB GTFS source zip; compressed GIS zips remain ordinary package files. Local `paper/*.pdf` reference copies are ignored from the public GitHub tree unless redistribution rights are separately cleared.

The exact OTP batch-query wrapper is not an active request. The paper documents OpenTripPlanner as the external runtime; the reproducibility value here is in the packaged GTFS generation workflow, inputs, scenario GIS layers, and access/frequency outputs.
